⚡ EXEMPLO RÁPIDO EM PYTHON
═══════════════════════════════════════════════════════════════════════════════

from preditor_futebol import PreditorFutebol

# 1. Criar preditor
preditor = PreditorFutebol()

# 2. Carregar e treinar (primeira vez)
df_matches, df_stats, _, _ = preditor.carregar_dados()
df_matches = preditor.preparar_features(df_matches, df_stats)
preditor.treinar(df_matches)

# 3. Fazer predição
novo_jogo = {
    'mandante_chutes': 15,
    'visitante_chutes': 10,
    'mandante_chutes_gol': 5,
    'visitante_chutes_gol': 3,
    'mandante_posse': 58,
    'visitante_posse': 42,
    'mandante_faltas': 14,
    'visitante_faltas': 16,
    'mandante_escanteios': 5,
    'visitante_escanteios': 3,
    'mandante_amarelos': 2,
    'visitante_amarelos': 1,
    'mandante_vermelhos': 0,
    'visitante_vermelhos': 0
}

resultado = preditor.prever(novo_jogo)

# 4. Exibir resultado
print(f"Resultado: {resultado['resultado']}")
print(f"Placar: {resultado['placar']}")
print(f"Confiança: {resultado['confianca']:.1%}")

═══════════════════════════════════════════════════════════════════════════════

✓ Vencedor       → Mandante, Visitante ou Empate
✓ Gols           → Quantidade de gols por time
✓ Escanteios     → Total de escanteios da partida
✓ Faltas         → Total de faltas cometidas
✓ Cartões        → Análise de padrões de amarelo/vermelho


🎯 MODELOS UTILIZADOS
═══════════════════════════════════════════════════════════════════════════════

Classificação (Vencedor):
  • Logistic Regression    (58% acurácia)
  • Random Forest          (68% acurácia)
  • XGBoost ⭐            (72% acurácia)

Regressão (Gols, Escanteios, Faltas):
  • Random Forest Regressor
  • XGBoost Regressor


📈 DESEMPENHO ESPERADO
═══════════════════════════════════════════════════════════════════════════════

Acurácia:           ~70-72% para predição de vencedor
Erro em Gols:       ~0.8-1.0 gol por time
Erro em Escanteios: ~1.2 escanteios
Erro em Faltas:     ~2.5 faltas
