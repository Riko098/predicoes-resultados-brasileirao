🎉 O QUE É NOVO?

Um novo programa que permite você escolher os times FLAMENGO x BOTAFOGO (por 
exemplo) e ver a predição personalizada para esse jogo específico!


🚀 COMO EXECUTAR

  $ python preditor_por_time.py


📊 O QUE VOCÊ PODE FAZER

┌────────────────────────────────────────────────────────────────────────┐
│ ✓ Escolher mandante e visitante em uma lista de 46 times             │
│ ✓ Ver predição completa com vencedor, placar, escanteios e faltas    │
│ ✓ Ver estatísticas médias de um time específico                      │
│ ✓ Comparar dois times lado a lado                                    │
│ ✓ Menu fácil e intuitivo                                             │
└────────────────────────────────────────────────────────────────────────┘


🏆 EXEMPLO PRÁTICO

Você quer saber: Como será Flamengo x Botafogo?

1. Execute: python preditor_por_time.py
2. Escolha opção 1: "Fazer Nova Predição"
3. Digite 21 (Flamengo) como mandante
4. Digite 9 (Botafogo-RJ) como visitante
5. Receba:
   
   ⚽ Resultado: Mandante vence (43% confiança)
   📋 Placar: 1 x 1
   🎲 Escanteios: 5
   📋 Faltas: 12
   
   Probabilidades:
   • Flamengo: 43%
   • Botafogo: 22.5%
   • Empate: 34.5%

📊 INFORMAÇÕES DA PREDIÇÃO

Quando você faz uma predição, você recebe:

  ⚽ VENCEDOR PROVÁVEL
     └─ Mandante, Visitante ou Empate

  🎯 CONFIANÇA
     └─ Porcentagem de certeza da predição (0-100%)

  📋 PLACAR ESTIMADO
     └─ Gols esperados para cada time

  🎲 ESCANTEIOS
     └─ Total de escanteios estimados na partida

  📋 FALTAS
     └─ Total de faltas esperadas

  📊 PROBABILIDADES
     └─ Distribuição de chances: Mandante, Visitante, Empate


🔍 DADOS USADOS

As predições são baseadas em:
  • Histórico completo de desempenho de cada time
  • Chutes, posse, faltas, escanteios, etc.
  • 9.165 partidas analisadas
  • Modelos de Machine Learning treinados

✓ Dados reais
